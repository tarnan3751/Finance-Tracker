# api_client

The Finance Tracker API client, generated from `api/openapi.yaml` by openapi-generator's
`dart-dio` generator with `built_value` serialization. Everything under `lib/` and
`.openapi-generator/` is generated: do not edit it. Change the contract, then run
`tools/gen_api_client.sh` and commit the result; the gate fails when
`.openapi-source.sha256` does not match the contract.

How the contract, the client and the contract tests fit together:
`docs/reference/api.md`.
